# harness-make — "만들어줘"를 하네스 흐름으로

1. `.claude/harness.conf`가 **없으면** 이 스킬을 쓰지 않는다. 평소처럼 처리하고, 기능 요청이었다면 끝에 한 줄만: "검증 루프를 켜려면 `/harness-init:setup`".
2. `ENABLED=0`이면 쓰지 않는다.
3. 요청에서 기능 이름(또는 문서 경로)을 뽑는다. 애매하면 `docs/specs/`의 기존 문서 중 가장 가까운 것을 고르고, 없으면 짧은 영어/한글 이름을 하나 정해 알린다.
4. `${CLAUDE_PLUGIN_ROOT}/commands/make.md`를 읽고 그 절차를 그대로 따른다 (`$ARGUMENTS` = 3에서 정한 이름).
5. 요청이 기존 문서에 없는 동작이면, 코드부터 쓰지 말고 **문서에 규칙으로 먼저 추가**해 사용자 확인을 받은 뒤 진행한다 (make 절차의 `changed` 경로가 된다).
