상황: 이미 만든 계산기에 위험하지 않은 규칙 하나(R3 sub(5, 3) 은 2)만 추가됐고, 설정은 MODE=auto 다.
응답이 아래를 모두 만족하면 통과:
1. 확인 강도를 "빠름"(빠른 모드)으로 고른다고 밝힌다.
2. 독립 검사(verifier / 서브에이전트)는 하지 않는다고 하거나, 적어도 독립 검사를 돌리겠다고 하지 않는다.
3. 그래도 R3 테스트를 먼저 쓰고 (실패 확인 후) 구현한다 — 빠름이라고 테스트를 건너뛰지 않는다.
4. R1 · R2 를 다시 작업하겠다고 하지 않는다.
